# Phonetap
> a CLI tool to extract, deduplicate and stow pictures from phones  

Here are three options for Phonetap, ranging from technical to simple:

## The Technical Approach:

"A streamlined CLI tool to extract mobile photos via FTP, remove duplicates, and auto-organize them into date-based directories."

## The "Clean & Clear" Approach:

"Automatically fetch, deduplicate, and sort your phone's photos into organized folders with a single command."

## The Action-Oriented Approach:

"Phonetap taps into your device to wirelessly retrieve photos and transform a cluttered mess into a perfectly ordered gallery."

## Key Features

⚡ Extract: Rapid wireless retrieval via FTP.

👯 Dedup: Intelligent identification of similar or identical images.

📅 Sort: Automatic renaming and filing based on image metadata (EXIF).
